# EquVolve

*数式が進化する様子を見てみましょう。* EquVolve（読み方は **エキュ・ヴォルヴ**）は、*equation*（数式）と *evolve*（進化する）を組み合わせた名前です。

> これは[英語版 README](https://github.com/bowo-prasetyo/equvolve/blob/main/README.md) の日本語訳です。内容に違いがある場合は英語版が優先されます。開発者向けの節は要約のみを掲載しています。

**EquVolve はデータに当てはまる数式を見つけ、その過程を見せてくれます。** 数式か数値の CSV ファイルを与えると、候補となる数式を交配させ、よく当てはまるものを残し、世代を重ねるごとに改善していきます。その間、当てはめた曲線と数式の木が画面に表示されます。この手法は*遺伝的プログラミング*（genetic programming、GP）と呼ばれ、この方法で数式を見つけることを*記号回帰*（symbolic regression）と呼びます。

GP のしくみを**学び、試してみる**ためのツールで、小さなデータセットに数式を当てはめるといった軽い実用にも使えます。すべてブラウザーの中で動きます。インストールは不要で、サーバーもなく、データがコンピューターの外に出ることはありません。

- デモ：[bowo-prasetyo.github.io/equvolve](https://bowo-prasetyo.github.io/equvolve/#/)
- リポジトリ：[github.com/bowo-prasetyo/equvolve](https://github.com/bowo-prasetyo/equvolve)

## できること

- **2 種類のデータ：** `x` の範囲でサンプリングした目標の数式、または自分の CSV ファイル。
- **複数の入力：** CSV には入力列を 10 列まで含められます。予測する列は自分で選べます。
- **リアルタイムの進化：** 進化はバックグラウンドで動くので、ページは操作できる状態のままです。高速モードでは画面の更新の間に多くの世代を進め、低速モードでは 1 世代ずつ表示します。
- **リプレイ：** 実行中のすべての改善を、1 つずつ、または再生して見返せます。数式、当てはまり、木が変わっていく様子がわかります。
- **読みやすい結果：** 最良の数式は表示前に簡略化され（`(2.469 + ((-2.507 + x*x) - -1.712))` は `pow(x, 2) + 1.674` になります）、木として描かれ、データの上にプロットされます。
- **進捗グラフ：** 最良の数式と典型的な数式が、世代ごとに目標に対してどれだけ当てはまっているかを示します。
- **エクスポート：** 最良の数式を、テキスト、JavaScript、Python、LaTeX のいずれかでコピーできます。
- **共有リンク：** クリック 1 回で、設定、データ（2,000 行まで）、最良の数式を含むリンクをコピーします。
- **調整できる探索：** 個体数、世代数、目標の当てはまり、進化の各種の率、木の深さ、プリセット付きの 23 個の演算子。
- **英語、インドネシア語、日本語：** 画面はブラウザーの言語に合わせて表示されます。上部のメニューで言語をすぐに切り替えられ、選んだ言語はこのブラウザーに記憶されます。
- **ライトテーマとダークテーマ：** グラフを含むページ全体が、既定ではデバイスの設定に従います。上部のボタンで「自動」「ライト」「ダーク」を切り替えられ、選択はこのブラウザーに記憶されます。
- **停止・再開・復元：** 実行を止め、設定を変えて続けられます。実行はブラウザーに保存されるので、タブを閉じても失われません。
- **実行前のチェック：** 無効な数式、範囲、設定は、実行を始める前にまとめて、直すべき設定の横に表示されます。数式がチェックされていない演算子（`x*x + 2/x` の `/` など）を使っている場合はそれを知らせ、ワンクリックでチェックを入れられます。

## クイックスタート

1. [デモ](https://bowo-prasetyo.github.io/equvolve/#/)を開きます。
2. 既定の数式 `x*x + 2` のまま **進化を開始** を押します。第 1 世代で見つかります。
3. 次は少し時間のかかるものです。数式を `x*x + 2/x` にします。この数式はチェックされていない `/` を使っていると表示されるので、**/ にチェック**（または演算子のプリセット **有理式**）を押してから **進化を開始** を押します。進捗グラフでは、赤い線が緑の破線の目標に向かって段階的に下がっていきます。たいてい 100 世代以内です。
4. 停止したら **▶ リプレイ** を押して、実行中に数式がどう改善されたかを見てみましょう。
5. 難しい問題に挑戦するなら、プリセット **すべて** で `sin(x) * exp(x/3)` を試してください。たいてい目標の少し手前で最大世代数に達して止まります。その後どうするかは[目標に届かないとき](#目標に届かないとき)で説明しています。

## 基本の考え方

- **プログラム：** 候補となる 1 つの数式です。演算子（`+` や `sin` など）、入力変数、数値から組み立てられます。EquVolve はそれぞれを数式と木の両方で表示します。
- **個体群：** 一度に試すすべてのプログラムです（既定では 200 個）。
- **世代：** 進化の 1 ラウンドです。最良のプログラムを残し、組み合わせ、少し変更して、次の個体群を作ります。
- **R²（当てはまり）：** プログラムがデータにどれだけ合っているかを表します。1 は完全な当てはまり、0 は常に平均値を予測するのと同程度、0 未満はそれより悪いことを意味します。最良のプログラムが**目標 R²**（既定では 0.999）に達した時点で実行は停止します。
- **最良のプログラム：** これまでで最も当てはまりの良いプログラムです。各プログラムのスコアにはサイズに応じた小さなペナルティが含まれるので、結果は短く読みやすいものになります。

## 使い方

アプリには番号の付いた 3 つのパネル、**1. データ**、**2. 設定**、**3. 結果** があり、実行ボタンは「設定」と「結果」の間にあります。そこまでスクロールするまでは実行ボタンがウィンドウの下部に表示されたままなので、スマートフォンでも **進化を開始** はいつでもワンクリックで押せます。

### 1. データ：何に当てはめるか

**データソース**を選びます。

**数式から生成：** 数式と X の範囲を入力します。

- 数式は `x` を使い、数値、括弧 `( )`、`+ - * /`、`sin(x)`、`pow(x, 2)`、`exp(-x*x)`、`abs(x)`、`PI * x` などの数学関数で書きます。JavaScript の `Math` にある名前はすべて、`Math.` を付けても付けなくても使えます。
- 結果も同じ表記なので、結果を新しい数式として貼り付け直せます。数式では、どの言語でも小数点にピリオドを使います（`0.5`）。
- **サンプル点の数**（既定では 101）の点が、両端を含めて X の範囲に等間隔で配置されます。実行ではこれらの点に当てはめます。

<details>
<summary>数式の詳細</summary>

- ほかに使えるもの：カンマ（`pow(x, 2)` のように）、`%`、`**`。それ以外（ほかの名前、文字列、角括弧、文）は受け付けないので、共有リンクに含まれる数式がほかのコードを実行することはありません。
- サンプル点の数は 2 から 10,000 までです。グラフに表示されるのは最大で約 60 点ですが、実行ではすべての点を使います。
- 数式が有限の値を持たない点（たとえば `x = 0` での `1/x`）は読み飛ばします。少なくとも 2 点は残る必要があります。

</details>

**データセットをアップロード：** 数値の CSV ファイルを選びます。通常は見出し行があります。

```csv
height,width,depth,price
1.5,4.4,4.1,27.4
2.0,3.0,2.8,22.7
```

- 1 つの列が**目的変数**、つまり予測する値です。既定では最後の列です。列が 3 つ以上あるときは、**目的変数の列** のメニューで別の列を選べます。
- ほかの列はすべて**入力**になり、見出しの名前が付きます（入力は 10 個まで）。
- **入力が 1 つ**のときはその名前は `x` になり、グラフにはデータと当てはめた曲線が表示されます。**入力が複数**のときは、各行の予測値と実測値の関係がグラフに表示されます。
- 空のセルがある行、セルが足りない・多すぎる行、数値ではなく文字がある行は読み飛ばします。何行を、ファイルのどの行を、なぜ読み飛ばしたかが表示されます（たとえば *2 行を読み飛ばしました：4 行目（空のセルがある）、9 行目（数値ではなく文字がある）。*）。
- 読み込むと、EquVolve が読み込んだとおりの最初の 5 行が、目的変数の列に印を付けて**プレビュー**表示されます。実行前に列を確認できます。
- ファイルが手元にない場合は、**サンプルデータを使う** で小さな例（箱の高さ・幅・奥行きから価格を求めるもの）を読み込めます。**サンプル CSV をダウンロード** で保存すれば、形式を確認したりテンプレートとして使ったりできます。

<details>
<summary>CSV の詳細</summary>

- 区切り文字にはカンマ、セミコロン、タブのどれでも使えます。1 つのファイルでは 1 種類の区切り文字だけを使い、最初の行から判定します（タブがあればタブ、なければセミコロン、それもなければカンマ）。カンマ以外のときは、読み込んだファイルの下にどの区切り文字だったかを表示します。
- **小数点のカンマ**は、ドイツ語、フランス語、インドネシア語などに設定した表計算ソフトが保存する、セミコロン区切りやタブ区切りのファイルで使えます。`1,5` は 1.5 として読み込みます。カンマ区切りのファイルでは、数値に小数点のピリオドを使う必要があります。桁区切り（`1.234,5`）には対応していないため、そのような行は文字として報告します。
- 二重引用符で囲んだセルには区切り文字を含められます（`"Height, cm"`）。引用符の中の `""` は 1 つの引用符を表します。Excel が *CSV UTF-8* ファイルに付ける UTF-8 の BOM は無視します。
- 最初の行がすべて数値の場合はデータとして扱い、列の名前は `x1`、`x2`、… と `y` になります。
- 使うのは最初の 10 個の入力列だけです。それ以降の列は無視し、読み込んだファイルの下にその名前を表示します。見出しよりセルが多い行は、値が列とそろわないため読み飛ばします（*セルが多すぎる*）。行末の区切り文字 1 つは問題ありません。
- 入力の名前は英字、数字、`_` だけに整えられるので、`Height (cm)` は `Height_cm` になります。数字で始まる名前や、`Math` の名前、JavaScript や Python のキーワードと重なる名前には `v_` が付きます（`sin` は `v_sin`）。同じ名前が繰り返される場合は `_2`、`_3`、… が付きます。
- 入力が複数のとき、グラフには最大 400 行を描きます。

</details>

### 2. 設定：探索の仕方

アプリでは、どの設定にも下に短い説明があります。たいていは **最大世代数**、**目標 R²**、**速度**、**演算子** だけで十分なので、表示されるのはこれらだけです。ほかの設定は GP の振る舞いを調べるためのもので、**詳細設定** の中にあります。詳細設定には既定値から変更した項目の数が表示され、いずれかに問題があると自動的に開きます。

| 設定               | 内容                                                                                             | 既定値  |
| ------------------ | ------------------------------------------------------------------------------------------------ | ------- |
| 最大世代数         | この世代数に達すると実行を一時停止します。値を上げて **再開** を押せます。                       | 500     |
| 目標 R²            | 最良のプログラムがこの当てはまりに達した時点で実行を停止します（1 = 完全、最大 1）。              | 0.999   |
| 速度               | **高速：** 画面の更新ごとに約 40 ms で処理できるだけの世代を進めます。**低速：** 更新ごとに 1 世代、毎秒約 6 世代で、観察向けです。 | 高速 |
| 演算子             | プログラムが使える構成要素です。                                                                  | `+ - *` |
| 個体数 *（詳細）*  | 一度に試すプログラムの数です。多いほど難しい数式も見つかりやすくなりますが、各世代は遅くなります（2 以上）。 | 200 |
| 交叉率 *（詳細）*  | 新しいプログラムが、1 つを複製する代わりに 2 つの良いプログラムの一部を組み合わせる頻度（0〜1）です。 | 0.7 |
| 突然変異率 *（詳細）* | 新しいプログラムにその後、小さなランダムな変更を加える頻度（0〜1）です。                       | 0.1     |
| エリート率 *（詳細）* | 変更せずに次の世代へ残す、最良のプログラムの割合（0〜1）です。                                 | 0.05    |
| トーナメントサイズ *（詳細）* | この数のプログラムをランダムに選んで競わせ、親を決めます。大きいほど最良のプログラムが強く選ばれます（1 以上）。 | 5 |
| 初期の木の深さ *（詳細）* | 最初に生成するランダムなプログラムの入れ子の深さです（1〜12）。                           | 4       |
| 最大の木の深さ *（詳細）* | どのプログラムも入れ子にできる深さの上限です（初期の木の深さから 17 まで）。当てはまりが良くならないままプログラムが大きくなり続けるのを防ぎます。 | 8 |
| 線形スケーリング *（詳細）* | 各プログラムをデータに合わせて伸縮・平行移動（`a + b·f(x)`）できるようにします。進化は正しい形を見つけるだけで済みます。これなしの GP を調べるのでなければ、オンのままにしてください。 | オン |
| 定数の最適化 *（詳細）* | 実験的な機能：各世代で、ランダムに選んだ 10% のプログラムの中の数値を微調整します。ベンチマークでは結果は改善しませんでした（[しくみ](#定数の最適化実験的)を参照）。 | オフ |

**数式に必要な演算子にチェックが入っていない場合**は、実行ボタンの上にその演算子を示す注記と、チェックを入れるボタン（たとえば **/ にチェック**）が表示されます。`pow(x, 2)` や `x**3` のような整数乗に必要なのは `*` だけです。`abs` のように演算子ではない数学関数も指摘されます。実行ではそれを近似することしかできません。

**演算子のプリセット：** 多項式（`+ - *`）、有理式（`/` を追加）、三角関数（`sin cos` を追加）、Exp / Log（`exp log` を追加）、すべて。データの形に合うプリセットを選んでください。よく選んだ少数の演算子のほうが、たいてい「すべて」より早く数式を見つけます。

<details>
<summary>23 個の演算子すべて</summary>

- 二項演算子：`+`、`-`、`*`、`/`、`pow`
- 単項演算子：`sin`、`cos`、`tan`、`sinh`、`cosh`、`tanh`、`asin`、`acos`、`atan`、`asinh`、`acosh`、`atanh`、`log`（自然対数）、`log2`、`log10`、`exp`、`sqrt`、`cbrt`

既定の率は、[結果の例](#結果の例)で説明しているベンチマークで選びました。交叉率 0.8、突然変異率 0.2、エリート率 0.02 では、難しい目標での結果がわずかに悪くなりました。

</details>

### 開始・停止・再開

| 状態     | ボタン                                                               | 設定                                               |
| -------- | -------------------------------------------------------------------- | -------------------------------------------------- |
| 待機中   | **進化を開始**                                                       | 変更できます。                                     |
| 実行中   | **実行中…**（無効）、**停止**                                        | ロックされます。                                   |
| 一時停止 | **再開**、**新規実行**、**共有リンクをコピー**、控えめな **結果を消去** | 変更できます。**再開** すると変更を反映して続けます。 |

- 強調表示されたボタンが、次に役立つ操作です。**停止** の後は **再開** です。再開してもすぐにまた止まってしまう場合（最大世代数に達している、またはすでに目標 R² に達している場合）は **新規実行** になり、続けるにはどの設定を上げればよいかがボタンの下に表示されます。完全な当てはまり（R² 1）の後は改善の余地がないので、**新規実行** を勧めます。
- 実行は、目標 R² または最大世代数に達すると自動的に一時停止し、どちらに達したかがメッセージで表示されます。最大世代数の後も続けるには、値を上げて **再開** を押します。
- **新規実行** は、現在の設定で最初からやり直します。
- **結果を消去** は、結果と保存された実行をすぐに消去し、新しい実行に備えます。
- **新規実行** や **結果を消去** の後は、元に戻すボタン（**新規実行を元に戻す** または **元に戻す**）で、前の実行を、そのときの設定とともに一時停止した状態で取り戻せます。別の実行を開始または再開するまで使えます。
- 設定は **進化を開始**、**新規実行**、**再開** を押したときにチェックされます。問題はすべてボタンの上に一覧表示され、各設定の横にも表示され、カーソルは最初の問題に移動します。修正すると一覧は更新されます。問題をクリックすると、その設定に移動します。
- **共有リンクをコピー** は、結果が表示されていて実行中でないときに表示されます。共有リンクを開いた後も表示されます。

### 3. 結果：読み方

- **最良の R²：** 最良のプログラムの当てはまりと、その意味を言葉で示します。*極めて良い当てはまり*（0.999 以上）、*非常に良い当てはまり*（0.99）、*良い当てはまり*（0.9）、*大まかな当てはまり*（0.5）、*悪い当てはまり*（0 以上）、*平均値を予測するより悪い*（0 未満）。
- **最良のプログラム：** これまでで最良の数式です。タブで数式、JavaScript、Python、LaTeX を切り替えられ、**コピー** で表示中のタブの内容をクリップボードにコピーします。入力が複数ある場合、エクスポートした関数はそれらを引数として受け取ります（例：`(height, width, depth) => …`）。
- **リプレイ：** 実行の後（または一時停止中）、**▶ リプレイ** ですべての改善を再生でき、スライダーで任意の改善に移動できます。数式、エクスポート、当てはまりのグラフ、木はすべてリプレイに追従し、進捗グラフにはその世代が青で示されます。**最新に戻る** で現在の最良のプログラムに戻ります。
- **当てはまりのグラフ：** 入力が 1 つのときは、データ（シアンの点）と最良のプログラム（赤い曲線）を表示します。軸の目盛りはきりの良い値で、軸には入力と目的変数の名前（`x` と `y`、または CSV の列名）が付きます。入力が複数のときは、各行の予測値と実測値の関係を、*実測値* と *予測値*（目的変数の名前付き）の軸で表示します。赤い対角線上の点は正確に予測されています。どちらのグラフも画面の幅に合わせて表示され、高解像度のディスプレイでも鮮明です。
- **進捗グラフ：** 各世代で、最良（赤）と中央値（灰色）のプログラムが完全な当てはまりにどれだけ近いかを示します。目盛りは R² 0.9、0.99、0.999 … が等間隔になるので、後半の小さな改善も、前半の大きな改善と同じくらい見やすくなります。緑の破線が目標 R² です。
- **式の木：** 最良のプログラムを木として表示します。各ノードには演算子、変数、数値のいずれかが表示され、演算子はオレンジ、変数は緑、数値はカーキ色です。ノードはラベルに合わせて大きくなり、長い数値は短縮されます（`1.76e-6`）。ポインターを合わせるとすべての桁が表示されます。
- **プログラムのサイズ：** 木のノードの数です。
- **速度：** 1 秒あたりの世代数です。
- **最近の世代：** 直近 5 回の画面更新それぞれの時点での最良のプログラムです。新しいものが上に表示されます。

<details>
<summary>エクスポートの詳細</summary>

- JavaScript と Python のエクスポートは有効数字 12 桁を保ちます。数式と LaTeX は、画面上の数式と同じく 5 桁で表示します。
- Python では累乗を `**` で書き、`cbrt` を使うプログラムには、`math.cbrt` には Python 3.11 以降が必要だというコメントが付きます。
- 高速モードでは 1 回の画面更新で多くの世代を進めるので、**最近の世代** では一部の世代が飛ばされます。
- 進捗グラフの目盛りは R² 0.999999 までです。それより良い当てはまりはグラフの下端に描かれます。

</details>

### 実行を共有する

実行の後、**共有リンクをコピー** を押すと、設定、データ、最良の数式を含み、すぐに実行できる状態で EquVolve を開くリンクがコピーされます。リンクはボタンの下のボックスにも表示されるので、必要なら手動でコピーできます。

- アップロードしたデータセットは、2,000 行以下なら含まれます。それより多い場合、リンクを受け取った人にファイルのアップロードを求めます。
- 実行中の個体群は含まれないので、受け取った人はあなたの実行を続けるのではなく、新しく実行を始めます。
- リンクを開いても、訪問者自身が保存している実行には、新しい実行を始めるまで影響しません。

### ブラウザーを閉じた後で復元する

実行は進行に合わせてこのブラウザーに保存されます。次に開いたときは、ページ上部のバナーで、何に当てはめていたか、どこまで進んだか、いつ保存したかとともに復元を提案します。**実行を復元** を押すと、結果、グラフ、リプレイ、設定、データとともに一時停止した状態で戻ります。**再開** を押すと続きを実行します。**後で** を選ぶと次回の訪問まで保存されたままになり、バナーが表示されている間もページはすぐに使えます。新しい実行を始めると、保存されていた実行は置き換えられます。何が保存されるかは[保存](#保存)を参照してください。

## 目標に届かないとき

実行はランダムで、見つけにくい数式もあります。最大世代数で止まるのはエラーではありません。それまでの最良のプログラムは表示されたままで、R² 0.99 でもすでにかなり当てはまっていることがよくあります（当てはまりのグラフで確認してください）。さらに近づけるには、次の順に試してください。

1. **最大世代数を上げて「再開」を押す。** 止まったところから実行が続きます。難しい目標では 1,000 世代以上かかることもあります。
2. **データの形に合う演算子を選ぶ：** 波には三角関数、増加・減衰・釣り鐘型の曲線には Exp / Log、割り算を含む数式には有理式。合った演算子を少し選ぶほうが、たいてい「すべて」よりうまくいきます。
3. **新規実行** で**やり直す**（新しい実行のほうが悪ければ、**元に戻す** で前の実行を取り戻せます）。実行は毎回異なるので、新しい実行ですぐに数式が見つかることもあります。
4. **個体数を増やす**（たとえば 500）。各世代は遅くなりますが、一度に多くを試せます。
5. 近い当てはまりで十分なら、**目標 R² を少し下げる**（たとえば 0.99）。

## しくみ

### 表現

プログラムは式の木です。葉は入力変数（`x`、またはデータセットの列名）か、[-10, 10] から一様に選んだ小数点以下 3 桁のランダムな定数です。新しい葉が変数になるか定数になるかは等確率です。内部ノードは有効な演算子です。葉の深さは 0 です。

最初の世代は *ramped half-and-half* で作ります。深さ 2 から初期の木の深さまで（初期の木の深さが 1 なら 1 のみ）、半分は「full」（すべての枝が最大の深さまで伸びる）、半分は「grow」（枝が途中で止まってもよい）で生成するので、さまざまな形から始まります。

### 適合度（fitness）

各プログラム `f` をすべての学習用の点で評価し、R²、つまりデータの分散のうち説明できる割合でスコアを付けます。

**線形スケーリング**（Keijzer, 2003）では、プログラムを `a + b·f(x)` として評価します。`a` と `b` は最小二乗法による最適値で、プログラムごとに厳密に計算します。進化は正しい形を見つけるだけでよく、定数の突然変異で正しいオフセットとスケールに偶然たどり着く必要はありません。表示されるプログラムには `a` と `b` が含まれ、簡略化によってプログラム自身の定数にまとめられます。

```
fitness = (1 − R²) + 0.001 × (ノードの数)
```

小さなサイズのペナルティが、プログラムの肥大化（*bloat*）を抑えます。いずれかの学習用の点で有限でない値（たとえばゼロ除算）を返すプログラムの適合度は無限大になります。目的変数が一定のときは R² が定義されないので、一定の目的変数は最初に拒否します。

### 各世代の処理

1. 個体群を適合度で並べ替えます。定数の最適化がオンなら、先にランダムに選んだ 10% のプログラムを最適化します（後述）。進捗グラフのために最良と中央値の R² を記録し、最良のプログラムが変わっていればリプレイのタイムラインに追加します。
2. 最良の R² が目標 R² 以上になるか、世代数の上限に達したら停止します。
3. ちょうど *個体数* 個のプログラムからなる次の世代を作ります。
   - **エリート：** 上位 *エリート率* の割合を、変更せずにコピーします。
   - **移民：** 多様性を保つため、10% をまったく新しいランダムなプログラムにします。
   - **子：** 残りです。それぞれトーナメント選択で親を選びます。*交叉率* の確率で、その親のランダムな部分木を、2 番目の親のランダムな部分木で置き換えます（90% の確率で演算子のノードを選ぶので、交叉で実際の構造が移ります）。最大の木の深さより深い子は拒否して交叉をやり直し、5 回失敗したら最初の親をコピーします。交叉しない場合は親をそのままコピーします。その後、*突然変異率* の確率で子に突然変異を加えます。
4. 突然変異は、等確率で次のどちらかです。
   - **部分木の突然変異：** ランダムなノードを、新しいランダムな「grow」の部分木で置き換えます。部分木は初期の木の深さより深くならず、プログラムが最大の木の深さを超えることもありません。
   - **点の突然変異：** ランダムなノードを 1 つ変更します。演算子は、同じ項数の別の有効な演算子に変わります（あれば）。定数はたいてい（70% の確率で）、粗い・中くらい・細かいのいずれかのランダムな幅（大きさの最大 ±1 倍、±0.1 倍、±0.01 倍。1 未満の大きさは 1 として扱う）でずらすので、定数を大きく動かすことも微調整することもできます。それ以外の葉は、新しいランダムな葉（変数または定数）に置き換えます。

### 定数の最適化（実験的）

線形スケーリングはプログラムの外側のオフセットとスケールを合わせますが、`exp(x/3)` の `1/3` のような関数の内側の定数は合わせません。有効にすると、定数の最適化が短い (1+1) 進化戦略でそれらを調整します。

1. プログラムのすべての定数にガウスノイズを加えます。
2. 適合度が改善すれば、その変更を残します。
3. 各定数のステップの大きさは、成功すると大きく、失敗すると小さくなります。

改善した定数は個体群に書き戻します。各世代で、ランダムに選んだ 10% のプログラムにそれぞれ 10 ステップを行います。

**改善しなかったため、既定ではオフです。** 非線形関数の内側に定数がある 3 つの目標（それぞれ 20 回、200 世代以内に R² ≥ 0.999 を目標）での結果：

| 戦略                                       | 達成    | 時間  |
| ------------------------------------------ | ------- | ----- |
| オフ                                       | **31 / 60** | **298 秒** |
| ランダムな 10% のプログラム、各 10 ステップ | 26 / 60 | 912 秒 |
| 最良のプログラムのみ、20 ステップ           | 21 / 60 | 418 秒 |
| 最良の 3 プログラム、20 ステップ            | 17 / 60 | –     |

最良のプログラムの定数を磨くと、それらがほとんどのトーナメントに勝つようになり、個体群の多様性が失われて探索が停滞します。ランダムな戦略は害が最も少ないものの、実行時間が 3 倍になります。探索が停滞したときにだけ定数を最適化するなど、多様性を保つ方法は今後の課題です。

### 速度

**高速** モードでは、ワーカーが約 40 ms の間、世代を連続して進め、それらをまとめた 1 回の更新を送ってから 5 ms 休みます。すべての世代は引き続き進捗グラフとリプレイに追加されます（[既知の制限](#既知の制限)の上限があります）。チェックポイントにだけ必要な個体群全体は、10 世代ごと、停止時、終了時に送ります。これは、毎秒約 20 世代が上限だったフェーズ 2 の世代ごとの 50 ms の固定の休止を置き換えたものです。個体数 200 では、一般的なブラウザーで演算子に応じて毎秒約 60〜100 世代進みます。**低速** モードでは、150 ms の休止を挟んで毎世代を送ります。

### 簡略化

プログラムは表示やエクスポートの前に簡略化されます。

- 定数をまとめます。
- 同類項をまとめます（`x + x` は `2 * x`、`x * x` は `pow(x, 2)` になります）。
- 定数を和に分配します。
- 割り算の中で因数を約分します（`(u / v) * v` は `u` になります）。
- `u * 1`、`u - u`、`u / u`、`pow(u, 1)` などの恒等式を取り除きます。

簡略化したプログラムは、すべての学習用の点で元のプログラムと照合し、同じ値を計算する場合にだけ使います。探索自体は簡略化していないプログラムで行います。

### 保存

セッションはブラウザーの IndexedDB に保存します（`gp-db`。この名前は EquVolve という名前より古いものですが、古いセッションも復元できるように残しています）。

- `sessions` には、最新の実行のチェックポイントを 1 つだけ、キー `latest` で保存します。内容は設定、データセット、世代、個体群全体（木はコンパクトな入れ子の配列で保存）、最良のプログラム、最近の世代、進捗グラフ、リプレイのタイムライン（最大 300 個のスナップショット）です。ワーカーから更新が届くたびに確認し、最良の適合度が改善したとき、または前回の書き込みから 10 世代以上経ったときに書き込みます。停止時、実行の終了時、実行中にページを閉じたときにも書き込みます。停止時と終了時に保存する個体群は正確ですが、それ以外のときは、チェックポイントのほかの部分より最大 10 世代古いことがあります。
- `bestPrograms` には、新しい最良のプログラムごとの記録（時刻、適合度、R²、世代、木）を残します。まだ画面には表示していません。

**結果を消去** は両方を空にします（**元に戻す** でチェックポイントを書き戻します）。テーマと言語の選択は別に、`localStorage` のキー `equvolve-theme` と `equvolve-language` に保存します。すべてブラウザーの中に残り、サイトのデータを消去すると削除されます。

### 既知の制限

- **非線形関数の内側の定数**（`exp(x/3)` の `1/3`）は突然変異だけで見つけるため、このような目標はフェーズ 1 より解ける頻度が低くなっています。[結果の例](#結果の例)を参照してください。実験的な定数の最適化でも改善しませんでした。
- **数式モードの変数は 1 つだけ**（`x`）です。複数の変数を使うには CSV が必要です。
- **簡略化は代数的なものだけ**です。三角関数や対数の恒等式は扱わず、因数分解もしません。
- **リプレイは最大 300 個のスナップショットを保持します。** 長い実行では途中の改善が間引かれます。最初と最新は常に残ります。
- **進捗グラフは最大 1,000 点を保持します。** それを超えると 1 点おきに間引きます（最新は常に残ります）。そのため、とても長い実行は粗い解像度で描かれます。

## 結果の例

`npm run bench` は、既定の設定（個体数 200、線形スケーリングはオン、定数の最適化はオフ）、101 個のサンプル点、x の範囲 [-3, 3] で、200 世代以内に R² ≥ 0.999 に達する頻度を測定します。各目標を 20 回ずつ実行します。すべて実行すると約 15 分かかります。GP は確率的なので、実行するたびに結果は異なり、20 回中数回の差はノイズの範囲内です。

| 目標                | 演算子            | フェーズ 1 | フェーズ 2 | このバージョン | 世代数の中央値 | 結果の例（このバージョン）                             |
| ------------------- | ----------------- | ---------- | ---------- | -------------- | -------------- | ----------------------------------------------------- |
| `x*x*x - 2*x + 1`   | `+ - *`           | 6          | 20         | **20**         | 9              | `pow(x, 3) - 2 * x + 1`                               |
| `3*x*x + 2`         | `+ - *`           | 17         | 20         | **20**         | 1              | `3 * pow(x, 2) + 2`                                   |
| `x*x + 2/x`         | `+ - * /`         | 19         | 20         | **20**         | 14             | `0.9716 * pow(x, 2) + 2.0113 / x + 0.087772`          |
| `exp(-x*x/2)`       | `+ - * / exp`     | **19**     | 11         | 13             | 22             | `0.99343 * exp(-0.54735 * pow(x, 2)) + 0.020478`      |
| `sin(x) + sin(x*x)` | `+ - * / sin cos` | **15**     | 12         | 12             | 19             | `sin(x) + sin(pow(x, 2))`                             |
| `sin(x) * exp(x/3)` | `+ - * / sin exp` | **7**      | 5          | 3              | 12             | `1.0273 * exp(0.30728 * x) * sin(x) + 0.023183`       |
| **合計（120 回中）** |                  | 83         | 88         | **88**         |                |                                                       |

この表からわかること：

- **多項式と有理式の目標は毎回解けています**（60/60。フェーズ 1 では 42/60）。たいてい数世代で解けます。ここでは線形スケーリングと部分木の交叉が効いています。
- **非線形関数の内側に定数がある目標**（`exp(-x*x/2)` の `1/2`、`exp(x/3)` の `1/3`）は、フェーズ 1 より解ける頻度が低くなっています（28/60。フェーズ 1 では 41/60）。フェーズ 1 ではすべての子のすべての定数をずらしていたため、たまたまこれらの目標に合っていました。実験的な[定数の最適化](#定数の最適化実験的)でもこの差は縮まりませんでした。
- **このバージョンの探索はフェーズ 2 とまったく同じ**です（定数の最適化は既定でオフ）。そのため世代あたりの結果はノイズの範囲内で一致します。世代ごとに 50 ms 休む代わりにまとめて処理するので、1 秒あたりでは速くなっています。
- 厳しい目標に届かなかった実行でも、たいてい R² 0.99 を超えるものを見つけています。例には、形は正しいものの定数がわずかに違う、惜しい結果が含まれています（`exp(x/3)` に対する `exp(0.307x)` など）。

## 開発者向け

EquVolve はビルド不要の静的サイトです。ローカルで動かすには、フォルダーを HTTP で配信してください（ブラウザーは `file://` のページから Web Worker を読み込めません）。

```bash
git clone https://github.com/bowo-prasetyo/equvolve.git
cd equvolve
python3 -m http.server 8000
```

その後 <http://localhost:8000> を開きます。テスト（`npm test` と `npm run test:ui`）やベンチマークの実行方法、プロジェクトの構成、ロードマップは、[英語版 README](https://github.com/bowo-prasetyo/equvolve/blob/main/README.md#running-locally) と[開発者ガイド](https://github.com/bowo-prasetyo/equvolve/blob/main/docs/DEVELOPMENT.md)で説明しています。
